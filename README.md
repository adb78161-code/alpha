THREATWATCH V17

GitHub Pages deployment package. Upload all files at the same level as index.html and keep the stickers/ folder.

Highlights: 24-hour session lifetime, multi-device connection tracking, independent device cards, improved reconnect/backoff, reduced signaling chatter, responsive desktop/tablet/mobile layouts, and self-contained sticker images in participant.html so the sticker gallery does not depend on a separate image path.

Long-distance WebRTC: STUN can establish many direct paths, but restrictive carrier NAT/firewalls require a TURN relay. Configure your own TURN service in peer-config.js for dependable cross-network relay. Do not publish TURN credentials in a public repository.
